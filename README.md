# Hobby
Repository containing many different mini-projects, mainly for experimenting with AI and computer science as a fun hobby.

# Rules
1. The code doesn't have to be clean, this is for fun, but it should stay understandable enough that I can come back to it later (see rule 2).
2. Every project must eventually be finished. New projects can be started even if previous ones aren't done yet, and it's fine to jump between them, but in the end everything has to get completed.
